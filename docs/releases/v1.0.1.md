# LegoBuilder v1.0.1 — BUG-88 Patch Release

**Released:** 2026-04-13  
**Type:** Patch (bug fix)  
**App ID:** `app-legobuilder-bugfix-20260412-gold`

## Summary

Critical bug fix: all interactive elements (click, drag, keyboard shortcuts) were non-functional despite the UI rendering correctly. This patch resolves all 6 root causes identified in the Low-Level Design.

## What's Fixed

### BUG-88: App loads but all interactive elements are non-functional

| Root Cause | Fix |
|------------|-----|
| RC-1: `useBrickPlacement` not mounted | Implemented full hook, mounted in `Viewport.tsx`, spread handlers onto `ViewportCanvas` |
| RC-2: `useKeyboardShortcuts` not called | Implemented full hook with all shortcuts, mounted in `App.tsx` |
| RC-3: Toolbar `onClick` handlers were no-ops | Wired buttons to `useUndoRedo` + `sceneStore` actions |
| RC-4: `BrickPalette` not calling `uiStore` | Wired click handlers to `setActiveBrickType`/`setActiveColor` |
| RC-5: `BrickInstances` not wiring `onClick` | Implemented `useSelection` with `handleBrickClick` |
| RC-6: CSS `pointer-events: none` blocking events | Removed blocking CSS, ensured `ViewportCanvas` forwards pointer events |
