## Summary

LegoBuilder v1.0.0 is the **initial production release** of a browser-based 3D LEGO brick builder. The application is a pure frontend SPA built with React 18, Three.js/React Three Fiber, and Zustand. It delivers a performant, accessible, and crash-resilient brick-building experience in the browser with no backend dependency.

## Features Shipped

### Core 3D Scene (FR-SCENE-001, FR-SCENE-002, FR-SCENE-003)
- Three.js WebGL canvas with 32×32 ground grid
- InstancedMesh batched rendering (single draw call for all bricks)
- BVH-accelerated raycasting: <2 ms for 500-brick scenes, ≥5× faster than naive
- Camera store with position/target/fov and `resetCamera()` action
- WebGL error boundary with accessible fallback

### Brick Interaction (FR-EDIT-001, FR-BRICK-004)
- Click-to-select with 1.8× highlight factor (zero React re-renders)
- Escape key clears selection
- R-key rotation of placement preview and placed bricks
- Occupancy-map footprint recalculation on rotation
- Undo/redo support via `RotateBrick` command pattern

### Placement Preview (FR-UI-003)
- Ghost brick preview following cursor
- Green/red valid/invalid placement indication

### Auto-Save & Crash Recovery (NFR-REL-001, FR-PERS-002)
- IndexedDB atomic dual-store writes every 30 seconds
- Orphaned session detection on page load
- Accessible `ResumePrompt` dialog (ARIA `role=dialog`, `aria-modal`, auto-focus)
- Quota-exceeded purge-and-retry
- Corrupted snapshot discard with graceful fallback
- `beforeunload` graceful-close marker
